我觉得好用的免费、开源Mac软件

2024/11/12

Bruno

本地 API 测试工具，类似于 Postman，但是各种 API 配置是以文件形式管理的，可以保存到 Git 上。

下载地址： https://github.com/usebruno/bruno

Cherry Studio

支持多个大语言模型（LLM）服务商的桌面客户端，方便快捷的使用各种 AI 服务。

下载地址： https://github.com/CherryHQ/cherry-studio/releases

Clipy

macOS 上的剪贴板扩展，可以记录多个复制的内容，方便后续使用。支持文本、图片等多种格式的剪贴板内容。

下载地址： https://github.com/Clipy/Clipy/releases

沉浸式翻译

提供网页双语翻译的浏览器插件，炸裂般好用。

下载地址： https://immersivetranslate.com/zh-Hans/

Easydict

简洁易用的词典翻译 App，支持输入翻译，划词翻译和 OCR 截图翻译，可同时查询多个翻译服务结果。

下载地址： https://github.com/tisfeng/Easydict/releases

OpenInTerminal

给 Finder 添加一些扩展，比如复制文件路径、在终端或 IDE 中中打开选择的文件等功能。

下载地址： https://github.com/Ji4n1ng/OpenInTerminal

whistle

web 调试代理工具。

下载地址： https://wproxy.org/whistle/

Xnip

Mac上方便好用的截图工具。

下载地址： https://zh.xnipapp.com/

zoxide

一个命令行工具，根据历史 cd 记录，提供了快速跳转目录的功能，类似于 autojump ，但是更快。

下载地址： https://github.com/ajeetdsouza/zoxide
