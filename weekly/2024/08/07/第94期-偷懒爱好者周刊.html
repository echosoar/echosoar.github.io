二、有趣的网站

本周分享 3 个有趣的网站

1. virtocean

这是一个可以听海洋中各种声音的网站，例如海浪、海鸟、海豚等等，适合在失眠时助眠。

virtocean

2. 艺术签名

这个网站生成连笔等各种样式的艺术签名，无需登录可以免费设计，非常好玩。

艺术签名

3. Oldweb Today

这个网站可以选择多种老旧的浏览器，输入网址并选择任意一个时间，就可以查看当时网站的效果，并且这个网站是在一个通过浏览器模拟的操作系统中打开的，所以你还可以在这体验不同的老旧操作系统。

Oldweb Today

三、好用的工具

本周分享 3 个在线工具

1. aisaver TTS

这是一个将文本转换为语音的在线工具，支持中文（甚至还可以选择广东话），无需登录可以免费使用。

aisaver TTS

2. NVIDIA NIM

这是由英伟达提供的免费大模型调用平台，支持最新的 Llama 3.1 405B 等模型免费调用。

NVIDIA NIM

3. VideoZip

这是一个在线视频处理工具，提供视频压缩、转码和导出音频功能，在浏览器端实现所以不会上传文件，从而可以很好的保护隐私，无需登录可以免费使用。

VideoZip

四、收藏的资源

本周分享 3 个收藏的数据资源。

1. 有用经验

这个网站收集了很多省钱、羊毛的技巧经验，帮助你在生活中有效避坑。

有用经验

2. Gitcharts

Github 已经成长为了一个由 2 亿用户的超大社区，这个网站提供了对 Github 很多维度的数据分析。

Gitcharts

3. indie hackers

独立开发导航站，可以帮助独立开发者发掘优秀的工具，也收录了广大优秀独立开发者创作的应用。

indie hackers
