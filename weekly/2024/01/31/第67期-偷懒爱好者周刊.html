三、好用的工具

本周分享 3 个在线工具

1. YesChat

这是一个提供与 GPT-4 与 Claude 2.1 模型聊天的工具，登录后每天可以免费使用 20 次 GPT-4。

YesChat

2. SVG Path Editor

这是一个在线编辑 SVG 图像路径的开源工具，无需登录可以免费使用。

SVG Path Editor

3. Github Profile

这是一个用来生成个人介绍页的在线工具，通过输入、点击选择等方式生成 Markdown 格式的个人介绍。

Github Profile
