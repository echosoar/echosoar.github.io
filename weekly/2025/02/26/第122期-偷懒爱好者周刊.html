二、有趣的网站

本周分享 3 个有趣的网站

1. Path Finder

非常炫酷的 3D 地图，3D 转换效果非常棒，还支持卫星地图和暗色模式，并展示当前实时天气

Path Finder

2. TopTimeline

探索名人生命中的关键事件和里程碑

TopTimeline

3. Home Apothecary

在家制作中医传统养生饮品的教程，输入原材料即可找到对应的熬制配方。

Home Apothecary

三、好用的工具

本周分享 3 个在线工具

1. Pixian.AI

免费的图像背景去取工具，去除背景的效果非常好。

Pixian.AI

2. 思政通

集成了大学中国近现代史、思修、毛概、马原四本教材内容的 AI 问答工具。

思政通

3. Git Podcast

输入一个 github 仓库地址，由 AI 生成介绍这个项目的播客音频。

Git Podcast

四、收藏的资源

本周分享 3 个收藏的设计资源。

1. Godly

这个站点收集了很多优秀的网站设计效果，可以帮助延伸网页设计灵感。

Godly

2. Dark Design

收集了各种暗色网站的视觉设计样式，提供 PC 和 H5 双端效果预览。

Dark Design

3. SVG Repo

一个收集了几十万个 SVG 图片的网站，支持按颜色、形状、填充等样式进行筛选。

SVG Repo
