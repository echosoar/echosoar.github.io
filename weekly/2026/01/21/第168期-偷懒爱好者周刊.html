二、有趣的网站

本周分享 3 个有趣的网站

1. 玻璃版俄罗斯方块

有玻璃质感的俄罗斯方块游戏，玩法虽然和传统的俄罗斯方块一样，但视觉效果非常独特。

玻璃版俄罗斯方块

2. Coding Cat

一个有趣的白噪音网站，中间偶尔会掺杂几声猫叫声。

Coding Cat

3. 怀旧 2006 版 QQ

有网友开发了这个怀旧 2006 版 QQ 界面，点击发送按钮还有滴滴滴的声音，以及用户昵称包含的火星文，非常有年代感

怀旧 2006 版 QQ

三、好用的工具

本周分享 3 个在线工具

1. 泡泡白噪音

一个功能非常齐全的白噪音网站，有两百多种不同的音效可以自由组合。

泡泡白噪音

2. Zoneless

可以添加全球多个城市的时间放在一个时间轴上，可以看到不同城市的昼夜变化的对应时区的时间。

Zoneless

3. 贝塞尔动画编辑器

可视化编辑和预览贝塞尔曲线动画的工具。

贝塞尔动画编辑器

四、收藏的资源

本周分享 3 个收藏的数据资源。

1. 哺乳纲演化

哺乳纲演化时间树，以沉浸式的方式展示从合弓纲到现代哺乳动物的演化历程。

哺乳纲演化

2. Agent Skills Marketplace

这个网站收录了七万多个智能体的技能。

Agent Skills Marketplace

3. subth.ink

输入一段文字，它会告诉你全球有多少人在这个网站写过几乎一模一样的文字。

subth.ink
