二、有趣的网站

本周分享 3 个有趣的网站

1. Ian's Shoelace

这个网站收集了 62 种鞋带的系法。

Ian's Shoelace

2. Last Museum

这个网站收录了五百多万件博物馆藏品的图片和信息。

Last Museum

3. Tiled Art

收集镶嵌艺术的网站，通过重复一个形状，仅使用这个形状铺满一个很大的画布。

Tiled Art

三、好用的工具

本周分享 3 个在线工具

1. Is Up Map

在一张图里面查看各大互联网网站是否服务正常。

Is Up Map

2. Can Agents Use

这个项目收录了各种网站面向 AI Agent 提供了哪些功能和服务，比如提供 CLI、API 还是 MCP。

Can Agents Use

3. Wikigraph

在星际中查看维基百科的链接关系，对外关联越多的词条越大。

Wikigraph

四、收藏的资源

本周分享 3 个收藏的数据资源。

2. Animation Vocabulary

Animation Vocabulary

3. Storied Colors

Storied Colors
