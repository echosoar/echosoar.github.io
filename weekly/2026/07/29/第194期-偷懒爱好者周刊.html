二、有趣的网站

本周分享 3 个有趣的网站

1. Whirlie

一个选择的俄罗斯方块，方块可以落在一个固定中心的转轴上，下落后会向较重的一侧倾斜90度，直到填完空格

Whirlie

2. 88x31

这个网站收录了 6500 多个 88x31 像素大小的 GIF 徽章

88x31

3. Read the Places

一份开放的地图集，收录了各种小说中出现的真实地点，并按故事发生的顺序排列

Read the Places

三、好用的工具

本周分享 3 个在线工具

1. Sticker

一个在线生成贴纸的工具，可以自定义富文本、图像生成贴纸，然后导出为 PNG 或动态的 GIF、MOV。

Sticker

2. icons0

号称最快的图标搜索引擎，支持从 150 多个图标库的几十万个 icon 图标中进行搜索

icons0

3. MobileGym

在 Web 上模拟了一个安卓系统，并在其中实现了一些常用的 App 的交互，适合给 AI Agent 做操作收集的训练和测试。

MobileGym
