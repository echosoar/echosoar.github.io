二、有趣的网站

本周分享 3 个有趣的网站

1. Windows XP

据说这是由月之暗面使用 Kimi K3 模型生成的一个 Web 版本的 XP，完成度非常高，里面的千千静听、QQ、红警都可以打开交互。

Windows XP

2. 乡土游戏馆

这个网站收录了各种炕头、晒场、课桌上传下来的老游戏，里面这个大炮轰小兵挺好玩的。

乡土游戏馆

3. MCJS

无需下载, 直接可以在浏览器里玩的 MineCraft 游戏。

MCJS

三、好用的工具

本周分享 3 个在线工具

1. Daily Integral

这是一个面向数学爱好者的网站，每日提供 3 道高质量的微积分题目挑战。

Daily Integral

2. Img to SVG Animation

这个工具可以将上传的图片提取内部轮廓和线条，转换为 SVG 动画。

Img to SVG Animation

3. Qm Icon

一个在线的图片设计工具，可以导出适配多种平台的格式。

Qm Icon

四、收藏的资源

本周分享 3 个收藏的数据资源。

1. LLM Score

LLM 大模型排行榜，综合 GPQA Diamond、SWE-Bench Pro、HLE 等Benchmark 的数据计算出性能指数，还根据模型的“输入价格、缓存命中价格、输出价格”计算综合价格指数。

LLM Score

2. Vault

这个网站提供了很多动画效果及其对应的提示词。

Vault

3. 小报童集合

收录了一千多个小报童专栏的信息，并提供一些简单的筛选。

小报童集合
