二、有趣的网站

本周分享 3 个有趣的网站

1. Stickertop Art

这个网站收集了很多贴在笔记本电脑上的有趣贴纸。

Stickertop Art

2. Ogden's Basic English

英国语言学家 C.K. Ogden 认为英语 850 个词就够了，这是根据这些词生成的一个在线词典，包含了每个词的定义、用法和例句。

Ogden's Basic English

3. Pokémon SVG Bench

这是一个使用 AI 生成宝可梦 SVG 的测试集，评测各种 AI 模型生成的效果。

Pokémon SVG Bench

三、好用的工具

本周分享 3 个在线工具

1. Papers With Code

这个工具提供了实时的热门人工智能研究论文数据，包含了代码、数据集等内容。

Papers With Code

2. 动态壁纸生成器

这个工具可以选择多种特效，然后可以调整特效的参数，生成动态壁纸。

动态壁纸生成器

3. KERN TYPE

在各种排版系统里面都有 Kerning，针对特定的字符对进行间距微调，让文字视觉上看起来更加协调自然。

KERN TYPE

四、收藏的资源

本周分享 3 个收藏的数据资源。

1. Math Curve Loaders

这个项目提供了多种基于数学公式计算绘制的曲线加载动画。

Math Curve Loaders

2. Mesh3D Gallery

收录了各种精美设计的 3D 网站的效果。

Mesh3D Gallery

3. Storied Colors

这个网站收集了各种颜色的来源故事。

Storied Colors
