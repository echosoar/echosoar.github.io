二、有趣的网站

本周分享 3 个有趣的网站

1. Open Grid Works

电力是 AI 时代的核心竞争力，这个网站可视化了全球电力基础设施的分布，包括电网、各种电站数据。

Open Grid Works

2. Meow Camera

24 小时在线的猫咪直播

Meow Camera

3. PCOL SNOOKER

一个在线 3D 斯诺克台球游戏。

PCOL SNOOKER

三、好用的工具

本周分享 3 个在线工具

1. PoseMy

一个特别好用的姿势编辑工具，有各种内置的姿势，也可以拖拽编辑 3d 的人物姿势，然后就可以让其他的生图的 ai 根据这个姿势，生成符合这个姿势的人物形象。

PoseMy

2. IP Address

这个工具可以查询 IP 地址、域名的各种信息，还提供了免费的 API。

IP Address

3. Web Check

输入一个网址，则可以检查该网站的各种信息。

Web Check

四、收藏的资源

本周分享 3 个收藏的数据资源。

1. Magnified Sand

这个网站收集了大量来自各个地区沙滩的沙子在显微镜下的照片。

Magnified Sand

2. Petdex

收录了各种用于 codex 的桌面宠物动画。

如果没有 codex，也可以看下我开源的这个只有几百 KB 大小的桌面宠物 App：https://github.com/echosoar/pure-pet

Petdex

3. Get Design

收集了各种网站的设计系统的描述文档（design.md），可以给 AI 进行参考使用。

Get Design
