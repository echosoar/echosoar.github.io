二、有趣的网站

本周分享 3 个有趣的网站

1. Diode

在线电路仿真工具，可以在线设计和仿真电路，支持多种元件和电路类型。

Diode

2. Animalist

一个测试英文单词的小游戏，只能输入和动物相关的单词，每输入一个就可以延长时间。

Animalist

3. Raft

一个完全使用 Claude Opus 4.6 AI 模型编写的单 HTML 文件 3D 木筏求生、建造游戏。

Raft

三、好用的工具

本周分享 3 个在线工具

1. Vibe Check

输入一个网站地址，即可检测这个网站是 AI 写的还是人工写的。

Vibe Check

2. CodeWiki

Google 开发的 AI 代码库分析工具，可以帮助开发者更好地去理解一个代码库的实现细节。

CodeWiki

3. Mockdown

通过可视化拖拽的方式来设计界面原型，特点是可以把设计的原型以 ASCII 的方式拷贝为文本，适合发送给 AI。

Mockdown

四、收藏的资源

本周分享 3 个收藏的数据资源。

1. Modern CSS

这是一个教程网站，提供了各种效果如何使用更加现代的 CSS 写法。

Modern CSS

2. Open Railway Map

这个网站提供了非常详细的全球铁路网络的可视化地图，可以查看铁路线路、速度、电气化状态等信息。

Open Railway Map

3. Markdown for Agents

由于AI Agent 需要结构化文本数据。这个工具将任何 URL 转换为简洁的 Markdown 格式。

Markdown for Agents
