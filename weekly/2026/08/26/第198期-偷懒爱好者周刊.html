二、有趣的网站

本周分享 3 个有趣的网站

1. Canyon Run

一个在线开小飞机的 3D 小游戏。

Canyon Run

2. Tomarigi

在一个 3D 地球上选择观看不同区域的摄像头直播。

Tomarigi

3. 养虾模拟器

一个有趣的在线 3D 水箱，可以投放虾、进行换水、清理苔藓等操作。

养虾模拟器

三、好用的工具

本周分享 3 个在线工具

1. Textures

为图片添加各种好看的滤镜，无需登录可以免费使用。

Textures

2. 液态玻璃球编辑器

通过各种参数的调整，生成不同效果的液态玻璃球，可以一键复制 React 和 SwiftUI 代码。

液态玻璃球编辑器

3. bloub

Grok Bot 风格的 SVG 吉祥物动画生成器。

bloub

四、收藏的资源

本周分享 3 个收藏的数据资源。

1. Model Capability Arena

一个模型能力竞技场，在同种提示词约束条件下对比不同模型的生成效果。

Model Capability Arena

2. Omniglot

一个关于世界文字与语言的百科站点，收录了几百种书写系统的字母表、发音规则和演变历史，还包括不少已消亡的古文字和人造文字。

Omniglot

3. 全球 Makers

一个全球创客社区，展示各地创客的项目和作品，可以直接导航到对应产品制作的视频教程。

全球 Makers
